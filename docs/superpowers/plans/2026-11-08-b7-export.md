# B7 · Export CSV e PDF — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O analista leva os números de um run para fora da plataforma: CSV dos eventos, dos cenários e da curva (os dois últimos com os filtros da tela), e PDF da aba aberta (Causal ou Elasticidade) em A4, legível e sem cortar gráfico.

**Architecture:** Três rotas GET finas em `api/routes/runs.py` (viewer+, `find_run`) leem o `results.json` ou o `engine.scenario` e devolvem o anexo; o texto sai de funções puras em `api/exports.py`, sobre o escritor pt-BR (`;`, vírgula decimal, BOM, `safe`) que sobe do `api/usage.py` para `api/csvfile.py`. O front põe `<a href download>` com os filtros na query e `window.print()`; o PDF é CSS `@media print` (Tailwind `print:`), com `@page` A4, tema claro forçado, um cabeçalho de impressão e um resumo dos filtros no lugar do painel.

**Tech Stack:** Python 3.13 + FastAPI + pytest (uv); React 19 + TanStack Router/Query, Tailwind v4, Playwright (bun). Nenhuma dependência nova.

**Spec:** `docs/superpowers/specs/2026-11-08-b7-export-design.md`. Leia também `CODE-STYLE.md`, `API-GUIDE.md`, `SECURITY.md` (CSV exportado escapa fórmula) e `docs/decisoes/dashboards.md` antes de começar.

**Decisões de leitura (verificadas ao escrever o plano):**
- **Rótulos dos motivos de evento.** O motor não tem lista dos motivos de evento: são literais em `engine/pipeline.py` (`_gate_reasons`, `analysis_failed`, `insufficient_run`) e `engine/results.py` (`not_selected`, `control_rejected`). O teste prende a tabela Python ao `REASON_LABELS` de `web/src/lib/results.ts`, lido do arquivo (mesmo texto na tela e no CSV), e confere que todo motivo dos eventos das fixtures reais (Gol e sintético) tem rótulo. É o mais robusto possível sem lista no motor: o `results.ts` é onde um motivo novo ganha rótulo hoje, e um código sem rótulo sai como o próprio código nos dois lugares.
- **Números.** `CODE-STYLE.md` não fixa formato de dinheiro (o `DATABASE.md` só fala de `NUMERIC`). Segue o `usage.py`: vírgula decimal, sem separador de milhar. Dinheiro, KPI e percentuais com 2 casas; ROAS, iROAS, R² e WMAPE com 4; p-valor com 3 algarismos significativos (vai a 1e-40). Datas `dd/mm/aaaa`, como na tela.
- **`safe()` só em texto.** Id do evento e nomes de canal passam pelo `safe()`; número não, porque um negativo começa com `-` e viraria texto no Excel.
- **404 antes do 409.** A rota `scenario` devolve 409 para run sem resultado (`runs.scenario` levanta `Blocked`); a spec quer 404 nos CSVs, como no `results`. Os CSVs da Elasticidade conferem o arquivo antes de chamar o `runs.scenario`; a rota `scenario` não muda.
- **Downloads da Elasticidade no E2E.** O motor falso devolve sempre a Gol, cuja elasticidade é recusada (409), e o `page.route` do `identificavel.json` vale para o `fetch` da tela, não sabemos se vale para um download por `<a download>` no Chromium. O E2E baixa de verdade só o `eventos.csv`; na Elasticidade confere o `href` dos dois links (caminho + filtros), e o conteúdo dos dois CSVs fica no pytest com o `identificavel.json`.
- **Gráficos no A4.** Na tela os gráficos ficam numa coluna de ~664 px (`max-w-5xl` menos o painel de 18rem); a largura útil do A4 com 12 mm de margem é 186 mm ≈ 703 px. Na impressão o `main` ganha `width: 186mm`: a impressão emulada (E2E, `page.pdf`) redesenha o Recharts nessa largura, e a do navegador, que não redimensiona o Recharts, já cabe. O E2E confere que nenhum `svg` passa da borda.
- **Cabeçalho de impressão.** Workspace pelo `me.workspaces` (nome; o slug se faltar), simulação e número do `RunOut`, data = `created_at` (a mesma da tela), status pelo `STATUS_LABELS`, motor pelo `engine_version`, grounding por `results.reports.grounding` (hoje sempre `null`, A9).

```python
def safe(cell: str) -> str:
    # Excel runs a cell that starts with these as a formula; names come from people. Only text goes through here:
    # a number we format may start with "-"
    return "'" + cell if cell.startswith(("=", "+", "-", "@", "\t", "\r")) else cell


def decimal(value: float | None, digits: int = 2) -> str:
    # a decimal comma and no thousands separator: Excel in pt-BR reads "1234,5" as a number
    return "" if value is None else f"{value:.{digits}f}".replace(".", ",")


def to_csv(header: list[str], rows: Iterable[list]) -> str:
    # ";" and a decimal comma, with a BOM: what Excel in pt-BR opens without the import wizard
    out = io.StringIO()
    writer = csv.writer(out, delimiter=";", lineterminator="\n")
    writer.writerow(header)
    writer.writerows(rows)
    return "﻿" + out.getvalue()
```

```python
"""The CSV exports of a run (B7): pure functions from the results.json, or the engine.scenario answer, to text."""

from api.csvfile import decimal, safe, to_csv

# labelled as REASON_LABELS in web/src/lib/results.ts; tests/api/test_exports.py keeps the two in step
EVENT_REASONS = {
    "not_significant": "Não significativo",
    "illogical_direction": "Direção ilógica (KPI contra o investimento)",
    "poor_fit": "Ajuste ruim no pré-período",
    "analysis_failed": "A análise do evento falhou",
    "not_selected": "Superado por outro evento do mesmo período",
    "placebo_failed": "Reprovado no placebo: o modelo acha efeito numa data sem intervenção",
    "insufficient_run": "Os dados desta execução não sustentam publicar lift",
    "model_dependent": "O efeito só aparece com as variáveis de mídia do modelo",
    "control_rejected": "Um controle foi descartado por acompanhar o investimento do canal",
}

EVENTS_HEADER = [
    "Evento",
    "Canais",
    "Início",
    "Fim",
    "Veredito",
    "Motivos",
    "Lift",
    "Lift IC inferior",
    "Lift IC superior",
    "Lift %",
    "p-valor",
    "Variação do investimento %",
    "Investimento incremental",
    "CPA incremental",
    "R²",
    "WMAPE",
    "Placebo p-valor",
    "Robustez p-valor",
]

# (label, key, decimals, revenue mode only)
TABLE_COLUMNS = [
    ("Investimento", "investment", 2, False),
    ("KPI", "kpi", 2, False),
    ("KPI p5", "kpi_lo", 2, False),
    ("KPI p95", "kpi_hi", 2, False),
    ("Receita", "revenue", 2, True),
    ("CPA", "cpa", 2, False),
    ("ROAS", "roas", 4, True),
    ("Investimento incremental", "incremental_investment", 2, False),
    ("KPI incremental", "incremental_kpi", 2, False),
    ("iCPA", "icpa", 2, False),
    ("iROAS", "iroas", 4, True),
]
CURVE_COLUMNS = [
    ("Investimento", "investment", 2, False),
    ("KPI", "kpi", 2, False),
    ("KPI p5", "kpi_lo", 2, False),
    ("KPI p95", "kpi_hi", 2, False),
    ("Receita", "revenue", 2, True),
    ("CPA", "cpa", 2, False),
    ("iCPA", "icpa", 2, False),
    ("ROAS", "roas", 4, True),
    ("iROAS", "iroas", 4, True),
    ("Investimento incremental", "incremental_investment", 2, False),
    ("KPI incremental", "incremental_kpi", 2, False),
    ("% incrementalidade", "pct_incrementality", 2, False),
]
RAMP_HEADER = ["Cenário", "Degrau", "Investimento", "KPI", "KPI p5", "KPI p95"]
SCENARIOS = [("current", "Atual"), ("recommended", "Recomendado"), ("saturation", "Saturação")]


def _day(iso: str | None) -> str:
    return f"{iso[8:10]}/{iso[5:7]}/{iso[:4]}" if iso else ""


def _p_value(value: float | None) -> str:
    # p-values reach 1e-40: three significant digits, not a fixed number of decimals
    return "" if value is None else f"{value:.3g}".replace(".", ",")


def _yes_no(value: bool | None) -> str:
    return "" if value is None else "sim" if value else "não"


def _event_row(event: dict) -> list[str]:
    row = [
        safe(event["id"]),
        safe(" + ".join(event["channels"])),
        _day(event.get("start")),
        _day(event.get("end")),
        "publicado" if event["status"] == "published" else "rejeitado",
        " · ".join(EVENT_REASONS.get(r, r) for r in event.get("reasons") or []),
    ]
    # a rejected event's numbers stay out of every export, as on the screen (docs/decisoes/dashboards.md)
    if event["status"] != "published":
        return row + [""] * (len(EVENTS_HEADER) - len(row))
    lift = event.get("lift") or {}
    lo, hi = lift.get("ci") or (None, None)
    fit = event.get("fit") or {}
    return row + [
        decimal(lift.get("abs")),
        decimal(lo),
        decimal(hi),
        decimal(lift.get("rel_pct")),
        _p_value(event.get("p_value")),
        decimal(event.get("investment_change_pct")),
        decimal(event.get("incremental_investment")),
        decimal(event.get("cpa_incremental")),
        decimal(fit.get("r2"), 4),
        decimal(fit.get("wmape"), 4),
        _p_value((event.get("placebo") or {}).get("p_value")),
        _p_value((event.get("robustness") or {}).get("p_value")),
    ]


def events_csv(results: dict) -> str:
    return to_csv(EVENTS_HEADER, [_event_row(e) for e in results["causal"]["events"]])


def _shown(columns: list[tuple], revenue_mode: bool) -> list[tuple]:
    return [c for c in columns if revenue_mode or not c[3]]


def scenario_csv(answer: dict) -> str:
    columns = _shown(TABLE_COLUMNS, answer["revenue_mode"])
    scenarios = [(label, answer[key]) for key, label in SCENARIOS if answer[key]]
    lines = [
        [
            label,
            *(decimal(row[key], digits) for _, key, digits, _ in columns),
            _yes_no(row["extrapolated"]),
            " · ".join(row["notes"]),
        ]
        for label, row in scenarios
    ]
    ramp = [
        [label, step["step"], *(decimal(step[k]) for k in ("investment", "kpi", "kpi_lo", "kpi_hi"))]
        for label, row in scenarios
        for step in row["ramp"] or []
    ]
    if ramp:
        lines += [[], RAMP_HEADER, *ramp]
    return to_csv(["Cenário", *(c[0] for c in columns), "Extrapolado", "Notas"], lines)


def curve_csv(answer: dict) -> str:
    columns = _shown(CURVE_COLUMNS, answer["revenue_mode"])
    lines = [
        [
            *(decimal(point[key], digits) for _, key, digits, _ in columns),
            _yes_no(point["extrapolated"]),
            _yes_no(point["in_filter"]),
        ]
        for point in answer["curve"]
    ]
    return to_csv([*(c[0] for c in columns), "Extrapolado", "No filtro"], lines)
```
